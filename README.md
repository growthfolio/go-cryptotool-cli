# CryptoTool — exercícios de criptografia em Go

> **Projeto educacional. Não use este código como biblioteca criptográfica de produção.**

Este repositório reúne exercícios feitos para estudar APIs e conceitos de
criptografia em Go. O objetivo é compreender melhor primitivas, formatos e usos
básicos de algoritmos conhecidos, e não criar uma implementação concorrente a
bibliotecas criptográficas auditadas.

## Temas estudados

O projeto contém exemplos relacionados a alguns destes temas:

- criptografia simétrica;
- criptografia assimétrica;
- funções hash e HMAC;
- assinaturas digitais;
- derivação de chaves;
- testes de implementação.

A presença de um algoritmo no repositório não significa que sua implementação tenha
sido auditada, validada contra todos os vetores relevantes ou considerada segura
para uso real.

## Segurança

Para software de produção, utilize bibliotecas mantidas e auditadas e siga a
documentação oficial da plataforma. Criptografia é uma área em que implementações
aparentemente corretas podem conter falhas difíceis de perceber.

Este projeto não é evidência de especialização profissional em criptografia; ele
registra uma etapa de estudo e experimentação.
